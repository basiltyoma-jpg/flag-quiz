# Угадай страну — викторина по флагам, территориям и дуэль вдвоём

Браузерная игра на чистом HTML + CSS + JavaScript (без сборки и без интернета).
Три режима: угадать страну по **флагу**, по **очертанию её территории** или написать
**название по флагу** самому. Есть **дуэль вдвоём** — двое игроков соревнуются на
одной и той же колоде вопросов. В режимах с вариантами в вопросе ровно **4 варианта
ответа**, количество раундов настраивается ползунком **от 1 до 50**.

**Играть онлайн:** https://basiltyoma-jpg.github.io/flag-quiz/

## Быстрый старт

Откройте `index.html` двойным щелчком — этого достаточно, всё работает офлайн
(картинки лежат в папке `assets`).

Если хочется запустить через локальный сервер:

```powershell
cd flag-quiz
python -m http.server 8000     # или: npx serve .
# затем откройте http://localhost:8000
```

## Режимы и уровни

| Режим | Что показывается | Лёгкий | Средний | Сложный | Невозможный |
|---|---|---|---|---|---|
| **Флаги** | государственный флаг | 36 | 60 | 70 | 70 |
| **Территории** | силуэт страны/территории | 36 | 60 | 69 | 64 |
| **Название по флагу** | флаг, название пишется вручную | 36 | 60 | 70 | 70 |

Числа в таблице — сколько стран доступно в режиме (эти же числа показаны на
карточках уровней в самой игре).

Уровни:

* **Лёгкий** — флаги, которые знают все: Россия, США, Германия, Япония, Бразилия…
* **Средний** — популярные страны: Польша, Вьетнам, Мексика, Кения, Катар…
* **Сложный** — малоизвестные страны: Бурунди, Мьянма, Лесото, Соломоновы Острова…
* **Невозможный** — микрогосударства, острова и заморские территории: Ватикан,
  Сан-Марино, Лихтенштейн, Ниуэ, Тувалу, Науру, Палау, Кирибати, Токелау,
  Острова Питкэрн, Антарктида, Остров Буве, Монтсеррат, Синт-Мартен и другие.

## Как играть

1. Выберите один из трёх режимов (флаги, территории или название по флагу), уровень
   сложности и число раундов.
2. В режимах с вариантами отвечайте кнопкой или клавишами <kbd>1</kbd>–<kbd>4</kbd>.
   В режиме «Название по флагу» название нужно **написать самому**: принимаются точные
   совпадения (в любом регистре, без знаков препинания) и опечатки в одну букву.
3. После ответа правильный вариант подсвечивается зелёным, ошибка — красным,
   и показывается правильное название. Дальше — кнопка «Дальше →»
   или <kbd>Enter</kbd> / <kbd>Пробел</kbd> (ещё переход происходит сам).
4. В конце — счёт, процент, словесная оценка и личный рекорд для выбранного
   сочетания режима и уровня (сохраняется в `localStorage` браузера).

Особенности настройки раундов:

* если стран в уровне больше, чем раундов, вопросы внутри игры не повторяются;
* если раундов больше (например, 50 при 36 странах в лёгком уровне), список
  стран проходится заново в новом порядке, но два одинаковых вопроса
  **не идут подряд** — об этом сообщает подсказка под ползунком.

## Дуэль вдвоём

Дуэль — это матч двух игроков на **одной и той же колоде** вопросов, без сервера:
сайт статический, поэтому соединение устанавливается напрямую между браузерами.

Как начать:

1. На главной в блоке «Дуэль вдвоём» введите имя и выберите способ связи:
   * **Две вкладки** — самый простой вариант: откройте `index.html` в двух вкладках
     или окнах одного браузера;
   * **Через интернет** — прямое WebRTC-соединение, игроки вручную обмениваются
     короткими кодами (хост присылает код-приглашение, гость — код-ответ).
2. **Хост** нажимает «Создать пати», получает код из четырёх символов и сообщает
   его сопернику. Настройки режима, уровня и числа раундов хост ставит на главной —
   они применяются для обоих игроков.
3. **Гость** вводит код пати и нажимает «Подключиться».
4. Хост нажимает «Начать дуэль» — оба играют одни и те же вопросы в одном порядке.
5. Счёт виден в панели над вопросом. Кто за матч дал больше верных ответов — тот
   и выиграл; при равенстве побеждает более быстрый. После матча можно сыграть
   ещё раз на тех же настройках.

В дуэли работают все три режима, включая «Название по флагу» — оба игрока пишут
ответ вручную.

## Обновление картинок

Все изображения лежат локально, поэтому игра работает без интернета.
Перекачать их (или добавить новые страны) можно так:

```powershell
# 1. добавьте страну в js/data.js (код ISO 3166-1 alpha-2, название, уровень)
# 2. скачайте картинки и обновите манифест
node tools/download-assets.js
```

Источники данных:

* флаги — `https://flagcdn.com/<код>.svg`;
* силуэты территорий — репозиторий [mapsicon](https://github.com/djaiss/mapsicon),
  файл `all/<код>/vector.svg`; чёрный силуэт при скачивании перекрашивается в
  светлый цвет, чтобы читаться на тёмном фоне.

Если для страны нет картинки (например, для `ps`, `fm`, `je`, `mh`, `mp`, `tv`,
`um` нет силуэтов в mapsicon), скрипт просто её пропустит, а игра не будет
показывать такую страну в соответствующем режиме — ошибок при этом не возникает.

## Проверки

```powershell
# данные, файлы и логика: 219 проверок, внешних зависимостей нет
node tools/selftest.js

# интерфейс в jsdom: 146 проверок (нужен npm install jsdom)
npm install jsdom
node tools/ui-test.js
```

`selftest.js` проверяет уникальность стран, наличие и размер всех картинок,
а также для каждого из 12 сочетаний «режим × уровень» — что генерируется нужное
число раундов, в каждом вопросе ровно 4 разных варианта и ровно один верный
(а в режиме «Название по флагу» — подсказка о числе букв и проверка ввода),
что картинка вопроса существует и что при 50 раундах вопросы не повторяются
подряд. Отдельно проверяется дуэль: код пати, имена, настройки, протокол
сообщений и полный матч «хост против гостя».

`ui-test.js` поднимает локальный HTTP-сервер, открывает страницу, переключает
режим и уровень, крутит ползунок, играет несколько раундов мышью и клавишами,
проверяет счёт, экран результатов, запись рекорда в `localStorage`, что все
запрошенные ресурсы (включая скрипты дуэли) отдаются сервером без 404 и что
сайт корректно работает из подпапки — так он выглядит на GitHub Pages.

## Публикация на GitHub Pages

Проект полностью статический, поэтому его можно бесплатно выложить в интернет:

1. Создайте на github.com пустой репозиторий (например `flag-quiz`) — без README
   и без .gitignore, они уже есть в проекте.
2. Залейте код:

   ```powershell
   cd flag-quiz
   git remote add origin https://github.com/<ваш-логин>/flag-quiz.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages** и выберите источник
   **GitHub Actions** (если он ещё не выбран).
4. После пуша отработает workflow `.github/workflows/pages.yml`, и игра станет
   доступна по адресу `https://<ваш-логин>.github.io/flag-quiz/`.

Все пути к файлам относительные, поэтому сайт корректно работает и из подпапки —
это отдельно проверяет `tools/ui-test.js`.


* Рекорды хранятся отдельно для каждого режима и уровня, в `localStorage`.
  В приватном режиме браузера они просто не сохраняются — игра не падает.
* Игра управляется не только мышью: <kbd>1</kbd>–<kbd>4</kbd> — ответ,
  <kbd>Enter</kbd> — дальше, <kbd>Enter</kbd> на экране результата — новая игра.
  В режиме «Название по флагу» ответ вводится текстом и подтверждается
  <kbd>Enter</kbd> в поле ввода.
* Вёрстка адаптивная: на узких экранах варианты ответа становятся в один столбец.

  угодно.
